怎么用这个站点

给谁看需要自己动手写 Skill、但还没有规范可依、不知道文档该怎么写的开发者。不需要任何前置知识。
怎么读先看下面的目录总览建立整体印象，再按「详细说明」的卡片顺序逐页读。新手建议按卡片顺序走一遍。
目录标记必需 技能运行所必需；可选 按需添加；给人看 不进模型上下文。
规则标记硬性 违反会导致技能无法被加载；建议 不做不报错但效果差；实验性 客户端支持不一。

什么是 Agent Skill

Skill 是用于扩展 AI agent 能力的轻量开放格式。它把「程序性知识」和「团队/项目专有上下文」打包成可移植、可版本化的文件夹，agent 按需加载。加载遵循渐进式披露：启动时只读 name + description（约 100 tokens），任务命中时才读整篇 SKILL.md，其余资源（脚本、参考、模板）在真正引用时才加载。

目录结构总览

必需 可选（按需加载） 给人看（不进模型上下文）
  • skill-name/技能根目录 · 目录名 = 技能名（kebab-case）
    • SKILL.md必需入口 + 资源路由表
    • references/可选按需加载的知识库
      • REFERENCE.md主技术参考
      • <domain>.md领域知识（finance.md / legal.md …）
      • api-errors.md条件触发的主题文档
      • FORMS.md表单 / 结构化数据格式
    • scripts/可选可执行脚本 · 确定性操作
      • build-report.py业务脚本（自包含）
      • validate.sh校验脚本
    • assets/可选静态资源
      • templates/输出模板
      • schemas/数据结构定义
      • data/查找表
    • evals/可选评测
      • evals.json测试用例 + 断言
      • files/测试输入文件
    • agents/可选厂商特定配置 · 非标准
      • *.yamlUI 元数据 / 依赖 / 调用策略
    • README / LICENSE / CHANGELOG给人看通常不必加；有分发要求时才用
